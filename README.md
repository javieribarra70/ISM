# ISM — Sistema FISM con paneles digitales sintéticos

Sistema de Modelado Estructural Interpretativo Fuzzy (FISM) que reemplaza paneles humanos tradicionales con paneles digitales sintéticos basados en LLMs.

## Estructura del monorepo

- `frontend/` — Plataforma colaborativa ISM existente (React + TypeScript + Vite + Express + Drizzle).
- `backend/` — Backend Python con FastAPI para los Bloques A, B, C del sistema FISM.
- `infra/` — Infraestructura compartida: docker-compose para Postgres local, configuración de servicios.
- `docs/` — Documentación del proyecto: prompts, decisiones de diseño, esquema de datos.
