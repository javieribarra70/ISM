Tengo un bug en React (Vite + shadcn/Radix Dialog): el modal del proceso VAXO/ISM no aparece cuando ya existen relaciones, aunque sí aparecen toasts indicando “Relaciones VAXO existentes”.

Diagnóstico probable (no lo ignores)

El modal <ISMProcess/> está renderizado dentro de ConnectionTab. Cuando hay relaciones existentes, el árbol de Tabs o el contenido del tab puede remontearse/desmontarse, y entonces el componente que contiene el Dialog no llega a montarse o se destruye inmediatamente. Parchar onEscapeKeyDown o onInteractOutside NO resuelve el problema si el componente se desmonta.
